# ToDo Timeline

Тестовое задание: простой сайт «Список задач», сделан с помощью Claude Code

Демо: https://todo-timeline-b93.pages.dev

## Что умеет

- Создать задачу: форма «Новая задача» справа или клик по пустому месту в сетке, на телефоне кнопка «+»
- Отметить выполненной: кружок на карточке
- Удалить: корзина на карточке или кнопка «Удалить» в форме, после удаления 4 секунды можно нажать «Вернуть»
- Задачи хранятся в localStorage и остаются после перезагрузки страницы

Дополнительно: неделя и список, перетаскивание задач на другое время и день, описание задачи, поиск с подсказками, скрытие выполненных, массовые действия в меню «…», версия для телефона

## Как запустить

Сборки нет. Откройте `site/index.html` в браузере или раздайте папку `site` любым статическим сервером

Один HTML-файл: HTML, CSS и JavaScript без библиотек, шрифт Manrope лежит в `site/assets`
